# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.1] - 2026-11-08

### Added

- Catalog dataset with six example audiovisual records.
- Search and filters by support, work type, and period.
- Dynamic catalog grid with result count and empty state.
- Detail view with metadata table, topics, and access notice.
- Reusable components for layout, home, catalog, detail, and about sections.
- Shared `DataTable`, `PageSection`, `FeatureCard`, and `RecordCard` components.

## [0.0.0] - 2026-11-08

### Added

- Initial Vite + React + TypeScript scaffolding.
- Base layout and visual styles for the Laboratorio de Patrimonio portal.
